Print the form

Prints in the F-031 layout, oldest first, with a new page as each one fills. Leave the dates blank to print everything, or set them to print from one audit to the next. Choose "Save as PDF" in the print window for a file.

Backup and import

The log is online, so every phone and computer sees the same record. Save to file keeps a backup copy, for the network drive or an audit. Load files (admin only, unlock it in Setup) adds entries from a file saved by the offline version of this log (your typed-in old sheets); entries already in the log are skipped.

Settings are locked

Machines, buttons and the form ID can only be changed with the admin password. Anything a button doesn't cover can be written in Other on the entry.

Company

Shows above the title on every phone, the same way the calculator and Part Checker show it. Not printed on the F-031 sheet. Fill in a name, a logo, or both.

Machines

The machine names in the dropdown and at the top of the printed form, in the order shown here; use the arrows to move one. Renaming a machine renames it on its existing entries too.

Print QR codes makes one code per machine, with the name under it. Scanning a machine's code opens the log with that machine already picked.

Filter buttons

Filters only: these print in the FILTER CHANGE column. In the order shown; use the arrows to move one.

Other buttons

Everything else done (oil added, oil type, tank cleaned): these print in the OTHER column, ahead of anything written. "To Other" and "To Filter" move a button between the lists, and every entry that used it moves with it.
