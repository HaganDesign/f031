New electrode set. The last set finished its 5 burns. Load a fresh set of 8; the orbit and depths below are back at the start values.
Chipped electrodes in this set? (electrode change only) Keep the chipped ones aside; they go on the chipped list for the maker.

Each electrode set is one F-030 sheet, newest first. Edit fixes a burn and keeps the old values in the history; only the last burn of the newest set can be deleted.

Prints one F-030 sheet per electrode set, landscape, for the sets with a burn in the dates picked (leave both empty for all).

Settings are locked

The start values, electrode count and form can only be changed with the admin password.

Electrode stock

Counted one electrode at a time, so opened sets and loose spares all count. Good on hand is the last physical count, plus deliveries, minus 8 for every new set started and 1 for every chipped one found since. Chipped ones are kept as their own pile for the maker until marked reported. Old sheets typed in later never count against stock.

Start values (burn 1 of every set)

Each burn adds the step to the orbit and to both depths (Y- goes more negative). The machine picked here is the one whose F-031 filter changes reset the filter count, and the reminder links straight to it.
